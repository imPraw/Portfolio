# Praw's portfolio

I'm Pratyush Halwai, a computer science student in Nepal. This is where I share what I've built and what I'm learning.

Built with Next.js, TypeScript, and Tailwind CSS.

To run it locally with Node.js 22 or newer:

```sh
npm ci && npm run dev
```

Optional settings are in [`.env.example`](.env.example).
