# Visual direction

Build the page around the supplied eclipse portrait. A violet sampled from the sky ties the image to the interface. Keep the opening title left-aligned and let the portrait resolve on the right. On small screens, let the image lead into the title so both have room.

Start with identity, follow with a short first-person introduction, then give each featured project a large framed preview and room for its implementation story. Use actual project captures where possible and visible labels on illustrations. Align the skill explorer, GitHub activity, timeline, and repository archive to the same grid. End with a direct invitation and a copyable email address.

Use Geist for display and body, Geist Mono for file names and metadata, and one accent across both themes. Keep motion to the transition between sections, the portrait, and interactive feedback. The content stays available with reduced motion.
